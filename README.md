# YouTube Subtitle Downloader

Скрипт для загрузки английских субтитров из видео YouTube с использованием библиотеки `pytubefix`


## Установка

Установите необходимую библиотеку:

```bash
pip install pytubefix
```

## Использование

1. Откройте файл со скриптом
2. Замените `"YourYTVideoUrl"` на URL нужного видео YouTube
3. Запустите скрипт:

```bash
python main.py
```

## Как это работает

1. Скрипт подключается к указанному видео с клиентом `WEB`
2. Получает список доступных субтитров. Если список пришёл пустым или запрос завершился ошибкой, запрос повторяется — всего до 5 попыток с паузой 10 секунд между ними (`ATTEMPTS` и `PAUSE_SECONDS` в начале файла)
3. Ищет субтитры с кодом, содержащим `"en"` (английские)
4. Если субтитры найдены, то сохраняет их в файл `subtitles.txt` (кодировка UTF-8)

## Обработка ошибок

- Если после всех попыток данные о субтитрах получить не удалось — скрипт завершится с кодом 1 и сообщением `"YouTube не отдал данные о субтитрах. Попробуйте позже"`
- Если список субтитров получен, но английских в нём нет — выведется сообщение `"Английские субтитры не были найдены :("`, код выхода 0
