# YouTube Subtitle Downloader

Скрипт для загрузки английских субтитров из видео YouTube с использованием библиотеки `pytubefix`


## Установка

Установите необходимую библиотеку:

```bash
pip install pytubefix
```

## Использование

1. Откройте файл со скриптом
2. Замените `"YourYTVideoUrl"` на URL нужного видео YouTube
3. Запустите скрипт:

```bash
python main.py
```

## Как это работает

1. Скрипт подключается к указанному видео YouTube
2. Ищет доступные субтитры с кодом, содержащим `"en"` (английские)
3. Если субтитры найдены, то сохраняет субтитры в файл `subtitles.txt` (кодировка UTF-8)

## Обработка ошибок

- Если не удается подключиться к видео — скрипт завершится с сообщением `"Не удалось достучаться до видео"`
- Если английские субтитры не найдены — выведется сообщение `"Английские субтитры не были найдены :("`
